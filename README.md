# 岩体CT扫描裂隙网络提取与可视化工具

基于Three.js构建的岩体CT扫描裂隙网络提取与可视化工具，支持加载图像序列或VTK体数据，使用Hessian滤波增强裂隙，提取裂隙面片，3D渲染并统计裂隙密度和方向玫瑰花图。

## 功能模块

### 1. 体数据加载模块
- 支持多种数据格式：
  - 图像序列：PNG、JPG、JPEG、TIFF、BMP、DICOM
  - VTK格式：.vtk、.vti
  - RAW格式：.raw
- 自动解析文件元数据（尺寸、间距、值范围）
- 提供合成裂隙数据生成功能用于测试

### 2. 裂隙增强模块
- **Hessian滤波**：基于二阶导数的多尺度裂隙检测
- **特征值分析**：识别板状结构（裂隙）的特征值模式
- **响应函数**：根据特征值比和板状结构判据计算裂隙响应
- **法线估计**：基于Hessian矩阵特征向量计算裂隙法线方向

### 3. 面片提取模块
- **Marching Cubes算法**：经典等值面提取算法
- 支持从原始体数据提取岩体表面
- 支持从裂隙响应体提取裂隙表面
- 自动生成顶点法线和标量值

### 4. 3D渲染模块
- 基于Three.js的高质量3D渲染
- 多光源系统（环境光、方向光、点光源）
- 阴影渲染
- OrbitControls相机控制（旋转、缩放、平移）
- 多种视图模式（正视图、侧视图、顶视图、3D视图）
- 透明度和可见性控制
- 顶点颜色映射（根据响应值着色）

### 5. 统计分析模块
- **裂隙密度计算**：裂隙体积占总体积的百分比
- **方向分布统计**：
  - 走向（Strike）分布直方图
  - 倾角（Dip）分布直方图
- **玫瑰花图绘制**：
  - 走向玫瑰花图
  - 倾角玫瑰花图
- **优势方向识别**：自动识别优势走向和优势倾角
- **统计报告导出**：支持导出文本格式的分析报告

## 使用说明

### 快速开始

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 在浏览器中打开 http://localhost:5173/

4. 点击「生成示例数据」按钮，或点击「选择文件」加载自己的数据

5. 调整裂隙增强参数，点击「执行裂隙增强」

6. 点击「提取裂隙面片」生成裂隙网格

7. 点击「计算裂隙统计」和「显示玫瑰花图」查看分析结果

### 参数说明

#### 裂隙增强参数
- **Sigma (σ)**：高斯核的标准差，控制检测尺度（0.5-5.0）
- **阈值**：特征值最小阈值，用于过滤噪声（0.001-0.1）
- **特征值比**：两个大特征值的最小比值，确保结构各向异性（0.1-0.9）
- **等值面值**：Marching Cubes提取裂隙的阈值（0.1-0.8）

#### 渲染控制
- **岩体透明度**：控制岩体表面的透明度（0-1）
- **裂隙透明度**：控制裂隙表面的透明度（0-1）
- **显示岩体/裂隙/边框**：控制各元素的可见性

## 算法原理

### Hessian滤波裂隙检测
对于三维图像I(x,y,z)，Hessian矩阵H为：
```
    [ Ixx  Ixy  Ixz ]
H = [ Ixy  Iyy  Iyz ]
    [ Ixz  Iyz  Izz ]
```

对于理想的板状裂隙，Hessian矩阵的三个特征值|λ1| << |λ2| ≈ |λ3|，其中λ1对应的特征向量为裂隙法线方向。

### Marching Cubes等值面提取
遍历体数据的每个立方体，根据8个顶点的值与等值面的关系，通过查表方式生成三角形面片。
