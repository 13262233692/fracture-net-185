# 岩体CT扫描裂隙网络提取与可视化工具

基于Three.js构建的岩体CT扫描裂隙网络提取与可视化工具，支持加载图像序列或VTK体数据，使用Hessian滤波增强裂隙，提取裂隙面片，3D渲染并统计裂隙密度和方向玫瑰花图。

## 功能模块

### 1. 体数据加载模块
- 支持多种数据格式：
  - 图像序列：PNG、JPG、JPEG、TIFF、BMP、DICOM
  - VTK格式：.vtk、.vti
  - RAW格式：.raw
- 自动解析文件元数据（尺寸、间距、值范围）
- 提供合成裂隙数据生成功能用于测试

### 2. 裂隙增强模块
- **预处理降噪**：高斯平滑去除高频噪声，降低噪声的二阶导数响应
- **Hessian滤波**：基于二阶导数的多尺度裂隙检测
- **多尺度分析**：在多个sigma尺度上计算Hessian响应，抑制单尺度噪声
- **特征值分析**：识别板状结构（裂隙）的特征值模式 |λ₁| << |λ₂| ≈ |λ₃|
- **结构显著性评分**：结合特征值大小和结构特征，抑制弱响应假裂隙
- **响应函数**：根据特征值比和板状结构判据计算裂隙响应
- **非极大值抑制**：3D邻域局部极大值抑制，细化裂隙响应
- **连通域过滤**：6邻域连通域分析，去除体素数不足的孤立小区域
- **法线估计**：基于Hessian矩阵特征向量计算裂隙法线方向

### 3. 面片提取模块
- **Marching Cubes算法**：经典等值面提取算法
- 支持从原始体数据提取岩体表面
- 支持从裂隙响应体提取裂隙表面
- 自动生成顶点法线和标量值

### 4. 3D渲染模块
- 基于Three.js的高质量3D渲染
- 多光源系统（环境光、方向光、点光源）
- 阴影渲染
- OrbitControls相机控制（旋转、缩放、平移）
- 多种视图模式（正视图、侧视图、顶视图、3D视图）
- 透明度和可见性控制
- 顶点颜色映射（根据响应值着色）

### 5. 统计分析模块
- **裂隙密度计算**：裂隙体积占总体积的百分比
- **方向分布统计**：
  - 走向（Strike）分布直方图
  - 倾角（Dip）分布直方图
- **玫瑰花图绘制**：
  - 走向玫瑰花图
  - 倾角玫瑰花图
- **优势方向识别**：自动识别优势走向和优势倾角
- **统计报告导出**：支持导出文本格式的分析报告

### 6. 渗流分析模块
- **图模型构建**：
  - 基于裂隙体素构建连通图模型
  - 节点表示裂隙体素中心，边表示6邻域连通关系
  - 边权重支持距离、开度、综合权重三种模式
- **连通分量分析**：
  - BFS算法识别独立裂隙网络簇
  - 计算簇数量、最大簇大小、簇分布统计
- **渗流路径搜索**：
  - Dijkstra最短路径算法
  - 支持自定义入口/出口边界（X/Y/Z正负面）
  - 多路径搜索，返回Top-N最优路径
  - 路径属性计算：总长度、最小开度、平均开度、弯曲度
- **渗流特性计算**：
  - 孔隙度（φ）：裂隙体积占总体积比例
  - 渗透率（k）：基于Kozeny-Carman方程估算
  - 连通性系数：节点间平均连通程度
  - 渗流概率：基于簇大小分布的渗流阈值估算
- **3D可视化**：
  - 网络节点/边可视化（Sphere+Line）
  - 渗流路径Tube管渲染（CatmullRom曲线+TubeGeometry）
  - 入口/出口边界标记
  - 独立可视化控制开关

## 使用说明

### 快速开始

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 在浏览器中打开 http://localhost:5173/

4. 点击「生成示例数据」按钮，或点击「选择文件」加载自己的数据

5. 调整裂隙增强参数，点击「执行裂隙增强」

6. 点击「提取裂隙面片」生成裂隙网格

7. 点击「计算裂隙统计」和「显示玫瑰花图」查看分析结果

### 参数说明

#### 裂隙增强参数
- **预处理降噪σ**：预处理高斯平滑的sigma，用于去除噪声（0-2.0）
- **最小检测尺度**：多尺度分析的最小sigma值（0.5-3.0）
- **最大检测尺度**：多尺度分析的最大sigma值（1.0-5.0）
- **尺度步长**：多尺度分析的sigma步长（0.25-1.0）
- **特征值阈值**：Hessian矩阵特征值的最小阈值，用于过滤噪声（0.001-0.1）
- **特征值比**：两个大特征值的最小比值，确保结构各向异性（0.1-0.9）
- **板状结构阈值**：最小特征值与中间特征值的比值阈值，判断是否为板状结构（0.05-0.3）
- **结构显著性**：结构显著性分数的最小阈值，抑制弱响应（0-0.1）
- **最小连通体素**：连通域分析的最小体素数，去除孤立假裂隙（5-100）
- **启用非极大值抑制**：是否启用3D非极大值抑制，细化裂隙响应
- **裂隙提取阈值**：Marching Cubes提取裂隙的等值面值（0.1-0.8）

#### 假裂隙抑制原理
1. **预处理降噪**：高斯平滑去除高频噪声，降低噪声的二阶导数响应
2. **多尺度分析**：在多个sigma尺度上计算Hessian响应，只保留在多个尺度上都存在的响应
3. **板状结构约束**：严格检查特征值模式 |λ₁| << |λ₂| ≈ |λ₃|，增加噪声比约束
4. **结构显著性评分**：结合特征值大小和结构特征计算显著性，抑制弱响应
5. **非极大值抑制**：3D邻域内只保留局部极大值，细化裂隙响应
6. **连通域过滤**：6邻域连通域分析，去除体素数不足的孤立小区域

#### 渲染控制
- **岩体透明度**：控制岩体表面的透明度（0-1）
- **裂隙透明度**：控制裂隙表面的透明度（0-1）
- **显示岩体/裂隙/边框**：控制各元素的可见性

## 算法原理

### Hessian滤波裂隙检测
对于三维图像I(x,y,z)，Hessian矩阵H为：
```
    [ Ixx  Ixy  Ixz ]
H = [ Ixy  Iyy  Iyz ]
    [ Ixz  Iyz  Izz ]
```

对于理想的板状裂隙，Hessian矩阵的三个特征值|λ1| << |λ2| ≈ |λ3|，其中λ1对应的特征向量为裂隙法线方向。

### Marching Cubes等值面提取
遍历体数据的每个立方体，根据8个顶点的值与等值面的关系，通过查表方式生成三角形面片。
